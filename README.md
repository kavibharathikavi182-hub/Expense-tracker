# 💰 Expense Tracker

A simple web-based Expense Tracker developed using HTML, CSS and JavaScript.

## 📌 About the Project

This project helps users track their income and expenses.

Users can add:
- Description
- Amount
- Transaction type
- Category
- Date

The application automatically calculates:
- Total Income
- Total Expense
- Balance

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ✨ Features

- Add income
- Add expenses
- Calculate total income
- Calculate total expenses
- Calculate balance
- Delete transactions
- Responsive design

## 🎯 Purpose

The purpose of this project is to practice front-end web development and JavaScript functionality.
